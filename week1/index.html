2. Input, loops and conditions

Create calculator.py. Start by reading one number, then extend the program to accept a list and calculate with its values.

The calculator gives you practice with a pattern used in many scripts: read some input, process each item and handle cases where the calculation cannot proceed. You will use the same pattern when processing file contents and web responses.

Read a number

Run the following code. Click in the Run pane, type 12 and press Enter.

calculator.py
text = input("Enter a number: ")
number = float(text)
print("Twice your number:", number * 2)

input returns text, even when you type a number. The call to float converts that text before the multiplication. Here = assigns a value to a variable and * multiplies it by 2. You should see 24.0; try 2.5 and -3 as well.

Enter numbers for now, using a decimal point where needed. If you enter a word such as hello, the conversion raises a ValueError. There is an exercise on handling this later in Part 2.

Read a list

Replace the code with the following and enter 12 3 2, separated by spaces.

replace calculator.py
text = input("Enter numbers separated by spaces: ")
parts = text.split()
print(parts)

The result, ['12', '3', '2'], is a list of strings. Notice the quotes: the values still need converting to numbers. split() separates the input at whitespace, so several spaces between numbers are fine.

Convert each item

Keep the first two lines and replace print(parts) with:

after parts = text.split()
numbers = []
for part in parts:
    number = float(part)
    numbers.append(number)

print(numbers)

Begin with an empty list, []. On the first pass, part holds "12"; on the next, it holds "3", and so on. Each pass converts one string and uses append to add the number to numbers.

The colon begins the loop body. Indent both statements by four spaces; PyCharm normally does this for you. The final print is outside the loop and runs once, displaying [12.0, 3.0, 2.0].

Move print(numbers) inside the loop. Predict what will be printed, then run it. Restore its original indentation afterwards.

Keep a running total

After the conversion loop, add:

add below the conversion code
total = 0
for number in numbers:
    total = total + number

print("Sum:", total)

Python evaluates total + number, then assigns the result to total. For 12 3 2, the total changes from 0 to 12, 15 and finally 17. Why must total = 0 be outside the loop?

Choose a branch

In a separate file, conditions.py, try this with a positive number, a negative number and zero:

conditions.py
number = float(input("Enter one number: "))
if number > 0:
    print("Positive")
elif number < 0:
    print("Negative")
else:
    print("Zero")

Python tests the conditions in order and runs the first matching branch. If neither comparison is true, it runs the else branch. The three headings must line up, with each print indented beneath its heading.

Use == for equality, != for inequality, and <, >, <= or >= for comparisons. A single = assigns a value. In float(input(...)), the input is read before conversion.

3. Counting HTTP responses

HTTP status codes tell us how a server handled a request. See Wikipedia's list of HTTP status codes for their meanings. The list below contains some successful responses and some failures. Create responses.py and use what you have just learnt to count them.

When a coursework script requests a page, check whether the request succeeded before interpreting the response. An error page can still contain plenty of text, but it will not contain the data you expected.

responses.py
statuses = [200, 403, 404, 200, 500, 302, 403, 200, 429, 500, 200, 404]

for status in statuses:
    if status >= 400:
        print("Failed request:", status)

The if statement runs once for each status in the list. To distinguish several categories, put a range check such as 200 <= status < 300 inside the loop:

example of a choice inside the loop
if 200 <= status < 300:
    print("Success")
elif 300 <= status < 400:
    print("Redirection")
else:
    print("Another category")

4. Bytes and bitwise operations

So far, you have worked with numbers and text. Files and network responses also contain binary data, which Python handles using bytes. Create working_bytes.py and compare the text with its encoded form below. A byte holds eight bits and has a value from 0 to 255.

Some coursework files contain binary data rather than readable text. Working with byte values lets you inspect and change that data without first converting it to characters.

Convert between text, bytes and a list

working_bytes.py
text = "caf\u00e9"
raw = text.encode("utf-8")
print("Characters:", len(text))
print("Bytes:", len(raw))
print("Byte values:", list(raw))
print("Hex:", raw.hex())
print("Text again:", raw.decode("utf-8"))

\u00e9 is an e with an acute accent. These four characters need five UTF-8 bytes: [99, 97, 102, 195, 169]. encode converts text to bytes; decode reverses that conversion. list(raw) shows the integer values and hex() gives two hex digits per byte.

You can also construct bytes from integers. Add this example; 0x denotes hexadecimal and 0b denotes binary.

add to working_bytes.py
values = [0x41, 0x42, 0x43]
raw = bytes(values)
print(raw)
print("First byte:", raw[0])
print("First two bytes:", raw[:2])

The first output is b'ABC', a byte sequence. Selecting raw[0] gives the integer 65, while raw[:2] gives the two bytes b'AB'. When constructing bytes from a list, each value must be between 0 and 255.

Apply bitwise operations

Each operator compares corresponding bit positions. AND produces 1 where both inputs have a 1; OR produces 1 where at least one does; XOR produces 1 where the bits differ.

bitwise operations
a = 0b10101010
b = 0b00001111
print("AND:", format(a & b, "08b"))
print("OR: ", format(a | b, "08b"))
print("XOR:", format(a ^ b, "08b"))

format(value, "08b") displays at least eight binary digits. Calculate the results before running: AND should give 00001010, OR 10101111 and XOR 10100101.

Use & and | for bits. Use and and or to combine conditions, such as number > 0 and number < 10.

Exercise A: change selected bits

For each question, start from value = 0b10100010.

  1. Use OR with a mask to set the lowest bit to 1.
  2. Use AND with a mask to clear the highest bit.
  3. Use XOR with a mask to toggle the lowest four bits.
  4. Print each result as eight binary digits. Explain which bits your mask preserves and which it changes.
Hint and expected results

A mask is a value whose bit pattern selects positions. Use 0b00000001, 0b01111111 and 0b00001111, respectively. The results are 10100011, 00100010 and 10101101.

Apply XOR to each byte

To transform a whole byte sequence, apply the operation in a loop:

XOR a byte sequence
original = b"Python"
key = 0x2A
changed_values = []
for value in original:
    changed_values.append(value ^ key)

changed = bytes(changed_values)
print("Changed hex:", changed.hex())

Each value is an integer. The loop XORs it with key and collects the results, which bytes converts back to a byte sequence. Python uses ^ for XOR and ** for powers.

Exercise B: recover the original bytes

  1. Write a second loop that XORs every byte of changed with the same key.
  2. Convert the recovered list to bytes. Print the recovered text and compare the bytes with original using ==.
  3. Repeat with original = bytes([0, 1, 127, 128, 255]). Display hex rather than decoding this binary input as UTF-8.
  4. Try a different recovery key and check the comparison. Explain why applying the same key twice reverses XOR.
Expected results

b"Python" becomes hex 7a535e424544. Applying 0x2A again recovers the original bytes and the comparison prints True. For the five-byte binary input, the transformed hex is 2a2b55aad5. Recovery should still be exact.

Another way to write the loop: list comprehensions

The list-building loop can also be written as a list comprehension:

equivalent list comprehension
changed_values = [value ^ key for value in original]
changed = bytes(changed_values)

The expression before for supplies each new item. Check that this produces the same result as the loop, then rewrite the recovery loop in the same form.

Additional operations: shifts, inversion and mutable bytes

value >> 1 shifts bits right; value << 1 shifts left. Python integers are not limited to eight bits, so use (value << 1) & 0xFF if you want to retain only the lowest byte. For an eight-bit inversion, use (~value) & 0xFF; ~value alone produces a negative integer for a non-negative input.

A bytes object cannot be changed in place. Try editable = bytearray(original), then editable[0] = editable[0] ^ 1. Convert back with bytes(editable). What changed, and why is the original unaffected?

This XOR operation is easy to reverse and is used here to practise working with bytes. For protecting data, see the encryption example later in the sheet.

from pathlib import Path

6. Downloading a web page

In Wikipedia's college list, the names are stored in an HTML table. Download the page now and save its response bytes, as you saved file bytes in Part 5. In Part 7 you will extract the names.

Saving a response lets you inspect what the server returned and develop your script without requesting the page again each time. Keep this distinction in mind when recording how you obtained your coursework evidence.

Open the article in a browser and find List of colleges. This is the table you will parse.

Create fetch_colleges.py:

fetch_colleges.py
from pathlib import Path
from urllib.request import urlopen

url = "https://en.wikipedia.org/wiki/Colleges_of_Durham_University"

with urlopen(url, timeout=15) as response:
    print("HTTP status:", response.status)
    print("Content type:", response.headers.get("Content-Type"))
    raw = response.read()

Path("colleges.html").write_bytes(raw)
print("Saved bytes:", len(raw))
print(raw[:200])

urlopen makes an HTTP GET request. read() returns the response body as bytes, which the script saves to colleges.html.

with closes the response after the indented block. timeout=15 limits a blocking network operation to 15 seconds.

Handling request errors

A failed request raises an exception. try runs the request; except handles a named error. In this version, else saves the response only after success.

fetch_with_errors.py
from pathlib import Path
from urllib.request import urlopen
from urllib.error import HTTPError, URLError

url = "https://en.wikipedia.org/wiki/Colleges_of_Durham_University"
try:
    with urlopen(url, timeout=15) as response:
        raw = response.read()
except HTTPError as error:
    print("HTTP error:", error.code)
except URLError as error:
    print("Connection failed:", error.reason)
except TimeoutError:
    print("The request timed out")
else:
    Path("colleges.html").write_bytes(raw)
    print("Saved bytes:", len(raw))

HTTPError is a kind of URLError, so catch it first. If the request fails, an existing colleges.html is left untouched.

7. Extracting the college names

Continue with this part after the practical, or start here if you have time left. Beautiful Soup lets you select elements from the saved HTML. It is installed as beautifulsoup4 and imported as bs4. Install it for your project before continuing.

The coursework includes finding information within web content. This exercise practises selecting relevant data and following links automatically, while checking that the script collects what you intended.

Create list_colleges.py. This code finds the college table and prints its first name:

list_colleges.py
from pathlib import Path
from bs4 import BeautifulSoup

raw = Path("colleges.html").read_bytes()
page = BeautifulSoup(raw, "html.parser")

heading = page.find(id="List_of_colleges")
if heading is None:
    raise ValueError("Cannot find the List of colleges section")

table = heading.find_next("table")
if table is None:
    raise ValueError("Cannot find the college table")

rows = table.find_all("tr")
first_row = rows[1]
cells = first_row.find_all(["th", "td"], recursive=False)
print(cells[1].get_text(" ", strip=True))

find locates the section marker; find_next selects the following table. The ValueError checks stop with an explanation if either is missing.

find_all("tr") returns the rows. Row 0 contains headings, row 1 the first college. Within that row, recursive=False selects the immediate cells: the shield, then the name. get_text(" ", strip=True) extracts the text and trims whitespace.

Encode and decode a message

Hex and Base64 represent bytes as printable text. Both can be decoded without a key. Create encoding_data.py:

encoding_data.py
import base64

text = "Meet at 10:30"
raw = text.encode("utf-8")

hex_text = raw.hex()
base64_bytes = base64.b64encode(raw)

print("Hex:", hex_text)
print("Base64:", base64_bytes.decode("ascii"))

from_hex = bytes.fromhex(hex_text)
from_base64 = base64.b64decode(base64_bytes, validate=True)

print(from_hex.decode("utf-8"))
print(from_base64.decode("utf-8"))
print("Same bytes:", from_base64 == raw)

b64encode returns ASCII bytes; decode("ascii") makes them a string. b64decode recovers the original bytes, and validate=True rejects characters outside the Base64 alphabet.

Encrypt and decrypt data

Fernet, from cryptography, encrypts data and checks for tampering during decryption. It uses the same secret key for both operations. Create encrypt_data.py:

encrypt_data.py
from cryptography.fernet import Fernet

key = Fernet.generate_key()
cipher = Fernet(key)

message = "A private practice message"
plaintext = message.encode("utf-8")
token = cipher.encrypt(plaintext)

print("Encrypted:", token.decode("ascii"))
recovered = cipher.decrypt(token)
print("Decrypted:", recovered.decode("utf-8"))

generate_key() produces a random key. The cipher object uses it to encrypt and decrypt bytes. The token is represented in Base64; decoding that representation alone does not recover the plaintext.

  3. Add the wrong-key experiment below at the end of your script.
  4. Test tampering as well as the wrong key. Use the hint below to change one byte inside a token without breaking its Base64 representation. Decryption must reject it.
Hint: alter a token while keeping valid Base64

Encrypt a file and write the recovered data

Add the following to encrypt a file and recover its contents, using the same cipher:

add to encrypt_data.py
from pathlib import Path

This script generates a new key each time it runs. Keep the original key if you want to decrypt a saved token later, and store it privately, separately from the file. Fernet protects the message but leaves the token's creation timestamp visible.

Read and write images

A PNG contains headers and compressed data. To work with its pixels, use Pillow. The supplied sample-image.png is a 96 x 64 image with red, green and blue blocks.

Read the pixels with Pillow

Create image_pixels.py. Pillow is imported as PIL:

image_pixels.py
from PIL import Image

with Image.open("data/sample-image.png") as source:
    print("Format:", source.format)
    print("Size:", source.size)
    print("Mode:", source.mode)
    image = source.convert("RGB")

print("Top-left pixel:", image.getpixel((0, 0)))
print("Middle pixel:", image.getpixel((40, 20)))

convert("RGB") loads a copy with red, green and blue channels. The with block closes the source file afterwards. Pixel coordinates (x, y) count from the top left; RGB values range from 0 to 255. These groups in parentheses are tuples.

Change a pixel and save; create a new image

Add this to image_pixels.py:

add to image_pixels.py
image.putpixel((0, 0), (255, 255, 255))
image.save("edited-image.png")

with Image.open("edited-image.png") as saved:
    print("Saved pixel:", saved.getpixel((0, 0)))

new_image = Image.new("RGB", (96, 64), (87, 43, 104))
new_image.save("created-image.png")

putpixel changes one pixel; save writes the image. Image.new creates a filled image. Open both files and zoom in to check the white pixel.

Encode a whole image as Base64, then write it back

The same Base64 conversion also works on a whole file. Create image_base64.py:

image_base64.py
import base64
from pathlib import Path

original = Path("data/sample-image.png").read_bytes()
encoded = base64.b64encode(original)
Path("image-base64.txt").write_text(encoded.decode("ascii"), encoding="ascii")

stored_text = Path("image-base64.txt").read_text(encoding="ascii")
restored = base64.b64decode(stored_text, validate=True)
Path("image-from-base64.png").write_bytes(restored)
print("Same file bytes:", restored == original)

The recovered image should match the original bytes. This example needs no Pillow.
