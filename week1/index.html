Read numbers and calculate results

Create calculator.py in the project root. Work through the small examples below before attempting the exercise. Run the script after each change so that you can see what it does.

1. Read one number

Enter this code and run it. Click in PyCharm's Run pane, type 12 after the prompt and press Enter.

Python: calculator.py
text = input("Enter a number: ")
number = float(text)
print("Twice your number:", number * 2)

input waits for you to type a line and returns it as text. float(text) converts that text to a number which can have a fractional part. = assigns a value to a name; * means multiplication. The result should be 24.0. Run it again with 2.5, then -3.

For now, enter numbers only, using a decimal point if needed. Entering a word such as hello causes a ValueError during conversion. Handling that error is an additional task below.

2. Split a line into separate values

Replace the file's contents with this example. Enter 12 3 2, with spaces between the numbers and no commas or brackets.

Python: replace calculator.py
text = input("Enter numbers separated by spaces: ")
parts = text.split()
print(parts)

The output is ['12', '3', '2']. This is a list, which stores items in order. The quotes show that its items are still text. split() separates the input at whitespace; several spaces between numbers are fine.

3. Use a for loop to convert each item

Keep the two lines that read and split the input. Replace print(parts) with:

Python: after parts = text.split()
numbers = []
for part in parts:
    number = float(part)
    numbers.append(number)

print(numbers)

[] creates an empty list. The loop takes each item from parts in turn and assigns it to part. On the first pass, part is "12"; on the next it is "3". Each pass converts one item and adds the number to numbers using append.

The colon starts the loop's block. Indent its two statements by four spaces. PyCharm normally inserts this indentation after you press Enter. The final print lines up with for, so it runs once, after the loop. The output should be [12.0, 3.0, 2.0].

Try this: temporarily indent print(numbers) so that it is inside the loop. Predict the output, run it and explain why you now see three lists. Move it back afterwards.

4. Keep a running total

Add this after the conversion loop. It visits the numeric list and adds each item to a running total.

Python: add below the conversion code
total = 0
for number in numbers:
    total = total + number

print("Sum:", total)

In total = total + number, Python calculates the right-hand side using the current values, then stores the result in total. For 12 3 2, the total starts at 0, then becomes 12, 15 and 17. It must be initialised before the loop. What would happen if total = 0 were inside it?

5. Make a choice with if, elif and else

Create a separate file, conditions.py, and run this example with a positive number, a negative number and zero:

Python: conditions.py
number = float(input("Enter one number: "))
if number > 0:
    print("Positive")
elif number < 0:
    print("Negative")
else:
    print("Zero")

if runs its indented block when the condition is true. Otherwise, elif tests the next condition. else handles the remaining case. Exactly one of these three messages is printed. Keep if, elif and else aligned.

Comparisons include == (equal), != (not equal), <, >, <= and >=. Use == to compare values; a single = assigns a value. The expression float(input(...)) reads the text first, then converts it.

Part 4: 20 minutes

Work with bytes and bits

Create working_bytes.py. A byte contains eight bits and has a value from 0 to 255. Python keeps text (str) separate from byte sequences (bytes).

1. Convert between text, bytes and a list

Run this example and compare the three ways of displaying the same data:

Python: working_bytes.py
text = "caf\u00e9"
raw = text.encode("utf-8")
print("Characters:", len(text))
print("Bytes:", len(raw))
print("Byte values:", list(raw))
print("Hex:", raw.hex())
print("Text again:", raw.decode("utf-8"))

\u00e9 represents an e with an acute accent. There are four characters but five UTF-8 bytes: [99, 97, 102, 195, 169]. encode converts text to bytes; decode interprets bytes as text. list(raw) makes a list of integer byte values, and hex() displays two hexadecimal digits per byte.

Add the following example. The prefix 0x introduces a hexadecimal integer; 0b introduces a binary integer.

Python: add to working_bytes.py
values = [0x41, 0x42, 0x43]
raw = bytes(values)
print(raw)
print("First byte:", raw[0])
print("First two bytes:", raw[:2])

The output is b'ABC', then 65 and b'AB'. The b marks a byte sequence. Positions start at zero. A slice such as raw[:2] stops before position 2. bytes(values) requires every integer to be in the range 0-255. Bytes can contain values that are not valid text, so do not decode arbitrary data simply to inspect it.

2. Apply bitwise operations

These operators work on the integer values, one bit position at a time. For each position, AND keeps a 1 only when both inputs have 1; OR needs at least one 1; XOR needs exactly one 1.

Python: bitwise operations
a = 0b10101010
b = 0b00001111
print("AND:", format(a & b, "08b"))
print("OR: ", format(a | b, "08b"))
print("XOR:", format(a ^ b, "08b"))

format(value, "08b") displays binary with at least eight digits, padding with leading zeros. Work out the results on paper, then run the code: AND gives 00001010, OR gives 10101111, and XOR gives 10100101.

Bitwise & and | operate on bits. The words and and or combine conditions, as in number > 0 and number < 10. They are not interchangeable.

Exercise A: change selected bits

Start with value = 0b10100010. Treat each question independently, starting from this original value.

  1. Use OR with a mask to set the lowest bit to 1.
  2. Use AND with a mask to clear the highest bit.
  3. Use XOR with a mask to toggle the lowest four bits.
  4. Print each result as eight binary digits. Explain which bits your mask preserves and which it changes.
Hint and expected results

A mask is a value whose bit pattern selects positions. Use 0b00000001, 0b01111111 and 0b00001111, respectively. The results are 10100011, 00100010 and 10101101.

3. Apply XOR to each byte

Add this example. It uses the same list-building pattern as Part 2:

Python: XOR a byte sequence
original = b"Python"
key = 0x2A
changed_values = []
for value in original:
    changed_values.append(value ^ key)

changed = bytes(changed_values)
print("Changed hex:", changed.hex())

Iterating over original gives integer byte values. The loop XORs each value with the key, then bytes converts the resulting list back to a byte sequence. ^ means XOR, not exponentiation; Python uses ** for powers.

Exercise B: recover the original bytes

  1. Write a second loop that XORs every byte of changed with the same key.
  2. Convert the recovered list to bytes. Print the recovered text and compare the bytes with original using ==.
  3. Repeat with original = bytes([0, 1, 127, 128, 255]). Display hex rather than decoding this binary input as UTF-8.
  4. Try a different recovery key and check the comparison. Explain why applying the same key twice reverses XOR.
Expected results

b"Python" becomes hex 7a535e424544. Applying 0x2A again recovers the original bytes and the comparison prints True. For the five-byte binary input, the transformed hex is 2a2b55aad5. Recovery should still be exact.

4. Write the loop as a list comprehension

A list comprehension is a shorter way to build a list. Replace the loop that builds changed_values with:

Python: equivalent list comprehension
changed_values = [value ^ key for value in original]
changed = bytes(changed_values)

Read it as: for each value in original, calculate value ^ key and put that result in the new list. Check that it produces exactly the same bytes as your loop. Then rewrite your recovery loop in the same form. Use the longer loop whenever it makes the code easier to understand.

Additional operations: shifts, inversion and mutable bytes

value >> 1 shifts bits right; value << 1 shifts left. Python integers are not limited to eight bits, so use (value << 1) & 0xFF if you want to retain only the lowest byte. For an eight-bit inversion, use (~value) & 0xFF; ~value alone produces a negative integer for a non-negative input.

A bytes object cannot be changed in place. Try editable = bytearray(original), then editable[0] = editable[0] ^ 1. Convert back with bytes(editable). What changed, and why is the original unaffected?

A repeated single-byte XOR key is useful for learning byte operations and simple obfuscation. It does not provide secure encryption. The later Fernet example uses an encryption library.

Download the Wikipedia page

Write a script to retrieve Wikipedia's Colleges of Durham University page. In Part 7 you will extract the names from its List of colleges table and save them in a text file.

Create fetch_colleges.py:

Python: fetch_colleges.py
from pathlib import Path
from urllib.request import urlopen

url = "https://en.wikipedia.org/wiki/Colleges_of_Durham_University"

with urlopen(url, timeout=15) as response:
    print("HTTP status:", response.status)
    print("Content type:", response.headers.get("Content-Type"))
    raw = response.read()

Path("colleges.html").write_bytes(raw)
print("Saved bytes:", len(raw))
print(raw[:200])

urlopen makes an HTTP GET request. response.read() reads the response body as bytes. The script saves those bytes in colleges.html and prints the first 200 bytes.

with closes the response when the indented block finishes. timeout=15 sets a timeout for blocking network operations. The content type should identify an HTML document.

Part 7: 25 minutes

List colleges and follow their links

Use Beautiful Soup to select the college names from the saved HTML. The package is installed as beautifulsoup4 and imported as bs4; see Requirements.

Create list_colleges.py. This starting example selects the table and prints the college in its first data row.

Python: list_colleges.py
from pathlib import Path
from bs4 import BeautifulSoup

raw = Path("colleges.html").read_bytes()
page = BeautifulSoup(raw, "html.parser")

heading = page.find(id="List_of_colleges")
if heading is None:
    raise ValueError("Cannot find the List of colleges section")

table = heading.find_next("table")
if table is None:
    raise ValueError("Cannot find the college table")

rows = table.find_all("tr")
first_row = rows[1]
cells = first_row.find_all(["th", "td"], recursive=False)
print(cells[1].get_text(" ", strip=True))

BeautifulSoup parses the saved bytes into HTML elements. It detects their character encoding. find(id="List_of_colleges") finds the section marker, and find_next("table") selects the table after it. The two raise ValueError lines stop the script with an explanation if the expected structure is missing.

find_all("tr") returns the rows. Row zero contains the column headings, so row one is the first data row. find_all(["th", "td"], recursive=False) selects that row's immediate cells. The first cell contains the shield and the second contains the college name. get_text(" ", strip=True) extracts text, separating nested pieces with spaces and removing surrounding whitespace.

Worked example 1: 10 minutes

Encode and decode a message

Encoding changes a representation. UTF-8 represents text as bytes; hexadecimal and Base64 represent bytes using printable characters. Neither hexadecimal nor Base64 needs a secret key to reverse it.

Create encoding_data.py:

Python: encoding_data.py
import base64

text = "Meet at 10:30"
raw = text.encode("utf-8")

hex_text = raw.hex()
base64_bytes = base64.b64encode(raw)

print("Hex:", hex_text)
print("Base64:", base64_bytes.decode("ascii"))

from_hex = bytes.fromhex(hex_text)
from_base64 = base64.b64decode(base64_bytes, validate=True)

print(from_hex.decode("utf-8"))
print(from_base64.decode("utf-8"))
print("Same bytes:", from_base64 == raw)

base64.b64encode(...) returns bytes containing ASCII characters. Decoding those as ASCII makes the printed representation easier to read. base64.b64decode(...) recovers the original bytes; validate=True makes the decoder reject characters outside the Base64 alphabet. UTF-8 decoding then recovers the message.

Exercise

Change the message to "caf\u00e9 at 10:30" and repeat the round trip. Does the final comparison still print True? Can you recover the message using only its Base64 representation?

Then change the Base64 text to include an exclamation mark and run the strict decoder. Record the exception. Explain why rejecting malformed Base64 does not establish that a successfully decoded message is authentic.

Expected result

The original message produces hex 4d6565742061742031303a3330 and Base64 TWVldCBhdCAxMDozMA==. Both decoding routes print Meet at 10:30. The comparison prints True, meaning the bytes match. Anyone with the encoded value can decode it; encoding provides no confidentiality.

Reference: Python base64 documentation.

Worked example 2: 15-20 minutes: cryptography package

Encrypt and decrypt data

Encryption protects a message using a key. We will use Fernet, an authenticated encryption tool from the cryptography package. It checks the encrypted message before returning decrypted data. The same secret key is used to encrypt and decrypt: this is symmetric encryption.

Create encrypt_data.py:

Python: encrypt_data.py
from cryptography.fernet import Fernet

key = Fernet.generate_key()
cipher = Fernet(key)

message = "A private practice message"
plaintext = message.encode("utf-8")
token = cipher.encrypt(plaintext)

print("Encrypted:", token.decode("ascii"))
recovered = cipher.decrypt(token)
print("Decrypted:", recovered.decode("utf-8"))

Fernet.generate_key() creates a random key. Fernet(key) prepares an object whose methods use that key. encrypt takes plaintext bytes and returns an encrypted token; decrypt returns the original bytes. You do not need to write a class to use these methods.

The token is represented in Base64, but Base64 decoding alone does not decrypt it. Its message contents are protected by the key; the token's creation timestamp is visible.

Exercise

  1. Run the script twice. Check that the encrypted output changes but the decrypted message stays the same.
  2. After creating token, add second_token = cipher.encrypt(plaintext) and print(token == second_token). Even with the same key and message, fresh randomness makes the tokens different.
  3. Add the wrong-key experiment below at the end of your script.
  4. Test tampering as well as the wrong key. Use the hint below to change one byte inside a token without breaking its Base64 representation. Decryption must reject it.
Hint: alter a token while keeping valid Base64

Append this to the script after creating token. bytearray is a mutable sequence of bytes, and ^ 1 changes one bit. Catch InvalidToken when attempting to decrypt the result, as in the wrong-key test.

Python: prepare a tampered token
import base64

token_bytes = bytearray(base64.urlsafe_b64decode(token))
token_bytes[-1] = token_bytes[-1] ^ 1
tampered = base64.urlsafe_b64encode(token_bytes)
Python: add to encrypt_data.py
from cryptography.fernet import InvalidToken

other_key = Fernet.generate_key()
other_cipher = Fernet(other_key)

try:
    other_cipher.decrypt(token)
except InvalidToken:
    print("This key cannot decrypt the message")

try attempts the decryption. except InvalidToken handles the failure and prints an explanation.

Expected result

The decrypted text is A private practice message. The wrong-key experiment prints This key cannot decrypt the message. With the original key, decryption succeeds.

Encrypt a file and write the recovered data

Add this to encrypt_data.py. It reuses cipher and its key from above. The same read/encrypt/decrypt/write steps work for any small file that fits in memory.

Python: add to encrypt_data.py

Read and write images

Use the supplied sample-image.png. It is a 96 x 64 pixel PNG with red, green and blue blocks.

Read and write the file bytes

Create image_bytes.py. This example needs no extra package.

Python: image_bytes.py
from pathlib import Path

raw = Path("data/sample-image.png").read_bytes()
print("First eight bytes:", raw[:8])
Path("sample-image-copy.png").write_bytes(raw)

The first eight bytes are b'\x89PNG\r\n\x1a\n': the PNG file signature. Open sample-image-copy.png in an image viewer. It is an exact byte copy. PNG file bytes include headers and compressed image data; they are not a simple sequence of RGB pixel values. Do not decode a PNG as UTF-8.

Read the pixels with Pillow

Create image_pixels.py. The package is installed as Pillow but imported as PIL.

Python: image_pixels.py
from PIL import Image

with Image.open("data/sample-image.png") as source:
    print("Format:", source.format)
    print("Size:", source.size)
    print("Mode:", source.mode)
    image = source.convert("RGB")

print("Top-left pixel:", image.getpixel((0, 0)))
print("Middle pixel:", image.getpixel((40, 20)))

Image.open identifies the image format. convert("RGB") loads a version with red, green and blue channels. The with block closes the source file afterwards; the converted image remains available.

A pixel position is a pair (x, y): x counts from the left, y from the top, starting at zero. An RGB colour is a triple (red, green, blue), with each value from 0 to 255. These comma-separated values in parentheses are tuples, which group values together.

Change a pixel and save; create a new image

Add this to image_pixels.py:

Python: add to image_pixels.py
image.putpixel((0, 0), (255, 255, 255))

putpixel changes the top-left pixel to white. save writes a PNG because the filename ends in .png. Image.new creates a new image filled with the chosen colour. Open both output files in an image viewer; zoom in to see the changed pixel.

C. Handle a failed request

An exception reports a problem. This version handles common request errors. Read it before running it; there is no need to send another request if you already saved the article.

Python: fetch_with_errors.py
from pathlib import Path
from urllib.request import urlopen
from urllib.error import HTTPError, URLError

url = "https://en.wikipedia.org/wiki/Colleges_of_Durham_University"
try:
    with urlopen(url, timeout=15) as response:
        raw = response.read()
except HTTPError as error:
    print("HTTP error:", error.code)
except URLError as error:
    print("Connection failed:", error.reason)
except TimeoutError:
    print("The request timed out")
else:
    Path("colleges.html").write_bytes(raw)
    print("Saved bytes:", len(raw))

HTTPError is a specific kind of URLError, so its handler comes first. The else block runs only if the request succeeds. On failure, an existing colleges.html is left unchanged; do not mistake it for a new download.
